# 🚀 ResuMatch 2.0

### AI-Powered Resume Intelligence Platform

ResuMatch 2.0 is a full-stack career intelligence platform designed to help job seekers analyze and improve their resumes.

## ✨ Features

- 📄 Resume PDF Upload
- 📊 ATS Score Analysis
- 🔍 Missing Keyword Detection
- 💼 Job Description Skill Analysis
- 🎯 Resume-to-Job Matching
- 💡 Resume Improvement Suggestions
- ✍️ Bullet Point Rewriter
- 🤖 Job Role Recommendations
- 📈 Resume Improvement Dashboard

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- CSS

### Backend
- Python
- FastAPI
- Pydantic
- PyPDF
